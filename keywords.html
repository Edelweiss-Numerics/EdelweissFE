Keyword reference

Every top-level keyword of the input file with its options. The syntax of an input file is described in Input file syntax. The tables are generated from each keyword’s option schema in edelweissfe/keywords/, the same schema the parser validates an input file against; edelweissfe --keywords prints the same information.

Many keywords only select a type (type=, solver=, generator=, …); the options of that type are documented on the page linked below the keyword.
